  2. Tools → Options → Expert Advisors → Allow WebRequest for: 72.56.99.191
  3. Attach EA to chart

Endpoints

GET/api/v1/mt5/symbols

List of trading pairs

Example response
{"symbols":[{"symbol":"SATL-WETH","base":"SATL","quote":"WETH"}]}
GET/api/v1/mt5/tick/:symbol

Current price tick

Example response
{"symbol":"SATL-WETH","bid":"0.00000123","ask":"0.00000125"}
GET/api/v1/mt5/stream

Real-time SSE price stream

Example response
data: {"type":"price","data":{"marketId":"SATL-WETH","bid":...}}
GET/api/v1/markets

All markets with current price

Example response
{"items":[{"id":1,"marketId":"SATL-WETH-UNI3-ETH","baseSymbol":"SATL"...}]}
GET/api/v1/candles/:marketId?interval=1h

OHLCV candles

Example response
[{"time":1234567890,"open":1.2,"high":1.3,"low":1.1,"close":1.25,"volume":5000}]
POST/api/v1/gas/encode-deposit

Encode GasStation deposit tx

Example response
{"to":"0x8133...","data":"0x..."}

Python Client Example

import requests, json

API = "http://72.56.99.191"

# Get all markets
markets = requests.get(f"{API}/api/v1/markets").json()
for m in markets["items"]:
    print(f"{m['baseSymbol']}/{m['quoteSymbol']} on {m['dexType']}")

# Get candles
candles = requests.get(f"{API}/api/v1/candles/SATL-WETH-UNI3-ETH?interval=1h").json()
for c in candles[-5:]:
    print(f"O:{c['open']} H:{c['high']} L:{c['low']} C:{c['close']}")

# SSE real-time stream
r = requests.get(f"{API}/api/v1/mt5/stream", stream=True)
for line in r.iter_lines():
    if line.startswith(b"data: "):
        tick = json.loads(line[6:])
        print(f"Price: {tick['data'].get('price')}")
